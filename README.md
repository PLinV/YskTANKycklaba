# YskTANKycklaba
Jeu Projet C avec bibliothéque Raylib

Bonjour mr De-Jonckere voici bienvenu sur notre magnifique jeu créer a l'aide de raylib.

On pourra clone le jeu en utilisant la commande suivante : 

```sh
git clone --recursive https://github.com/PLinV/YskTANKycklaba.git
# compiler raylib : 
cd YskTANKycklaba.git/raylib/src
make PLATFORM=PLATFORM_DESKTOP
cd ../../

#Pour lancer le jeu : 
make 
./prog

#Pour avoir du son(si ça fonctionne pas essayer) : 
sudo apt-get update
sudo apt-get install libasound2-dev libpulse-dev
```
